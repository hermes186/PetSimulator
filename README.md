## 📖 项目概述

**Pet Simulator** 是一款使用 C++ 后端和原生 JavaScript 前端开发的宠物养成游戏。玩家可以创建、培养、交易虚拟宠物，并与其他宠物进行战斗。

### 核心特性

- 🐶 **宠物管理** - 创建、培养、删除宠物
- ⚔️ **战斗系统** - 宠物对战、获取经验
- 🎒 **背包系统** - 道具管理和使用
- 🛒 **商城系统** - 购买道具和装备
- 💾 **数据持久化** - 自动保存游戏进度
- 📱 **响应式设计** - 深色主题、现代 UI

## 🚀 快速开始

### 系统要求

- Windows 11 或更高版本
- WSL2 环境
- MinGW g++ 编译器
- 4GB+ RAM
- Chrome/Edge/Firefox 浏览器

### 安装和运行

1. **克隆项目到本地**
   ```bash
   git clone https://github.com/hermes186/PetSimulator.git
   cd PetSimulator
   ```

2. **编译后端**
   在 Windows 命令提示符（CMD）或 PowerShell 中运行：
   ```cmd
   compile.bat
   ```

3. **启动服务器**
   运行启动批处理文件开启 HTTP 服务：
   ```cmd
   start_server.bat
   ```

4. **访问游戏网页**
   打开浏览器，访问以下地址进入游戏界面：
   ```
   http://localhost:8080/
   ```

详细步骤请查看 [快速入门指南](QUICKSTART.md)

## 🎮 游戏玩法

### 🏠 我的宠物
查看和管理你的宠物队伍。支持按类型（火焰系、水系、机械系）筛选。

- 最多可拥有 5 只宠物
- 可以查看宠物详细属性
- 支持删除（放生）宠物

### ✨ 召唤宠物
使用金币召唤新宠物（每次 200 金币）

- 🔥 火焰系宠物
- 💧 水系宠物  
- ⚙️ 机械系宠物

### ⚔️ 竞技场
选择宠物进行战斗

- 获取经验值和金币
- 战斗记录显示详细日志
- 宠物获胜获得奖励

### 🎒 背包
管理购买的道具

- 生命药水 - 恢复宠物生命值
- 攻击药水 - 临时增加攻击力
- 经验加倍卡 - 下次战斗双倍经验
- 宠物粮食 - 增加全属性
- 召唤卷轴 - 免费召唤一次
- 复活石 - 复活失败宠物

### 🛒 商城
购买各种道具和装备

- 支持金币和钻石两种货币
- 自动扣费和计数

## 🐛 已知问题

目前已知的核心 bug 及安全隐患已全部清零。

### 安全与稳定性加固（已完成）
- [x] **路径遍历防护 (Path Traversal)** - 拦截任何包含 `..` 的畸形请求，防止敏感数据泄露。
- [x] **空请求头崩溃防护 (DoS)** - 修正空头和纯空格头的字符串截取逻辑，增加全局异常捕获，确保服务器稳定运行。
- [x] **TCP 粘包与分段接收修复** - 支持 `Content-Length` 解析与多段接收机制，彻底解决接口偶发性 `400` 报错。
- [x] **命令行解析兼容性修复** - 编译和启动批处理脚本完全纯英文化并置换为 CRLF 换行符，兼容所有 Windows 系统语言环境。

### 次要遗留
- ⚠️ `/api/status` 端点未实现（显示"离线模式"，不影响功能）
- ⚠️ 宠物 ID 会在删除后重新编号（因为使用数组索引，在 MVP 阶段可接受）
